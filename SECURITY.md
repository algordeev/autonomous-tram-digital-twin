# Security Policy

This repository is a research simulator, not safety-certified railway control
software. It must not be connected to a real vehicle or wayside device without
independent hazard analysis, fail-safe hardware and applicable certification.

If you discover a vulnerability that could affect a deployed web build or a
future hardware adapter, contact the repository owner privately through the
GitHub profile rather than opening a public issue. Include reproduction steps,
affected version and potential impact.

Only the latest revision on `main` is expected to receive security fixes.
