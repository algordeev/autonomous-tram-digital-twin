# Цифровой двойник автономной трамвайной системы

Исследовательский прототип для моделирования движения трамваев,
пассажирского обслуживания, диспетчеризации и управления энергией тяговой
сети.

В проекте объединены C++/WebAssembly-ядро управления, слой сценариев и
экспериментов на TypeScript и интерфейс React/Canvas. Реализованы маршруты №2 и
№21 Нижнего Новгорода и линия Konak Tram в Измире.

![Сценарий Измира](docs/assets/simulator-overview.png)

## Реализовано

- движение нескольких трамваев без обгона;
- остановки, пассажиры, вместимость, посадка и высадка;
- двери, стрелки, трамвайные и автомобильные светофоры;
- интервальное регулирование и отправления с конечных;
- заезд и выход из депо, резервный вагон и нештатные ситуации;
- физика разгона и торможения, масса пассажиров, кривые, стрелки и уклоны;
- рекуперация, тяговые секции, подстанции и маховичные накопители;
- график «время–расстояние»: выбор маршрута, история за 10–60 минут, стоянки
  и подсветка опоздания отправлений;
- headless-эксперименты и сравнение энергетических стратегий.

## Быстрый запуск

Нужны Node.js 22.13+, npm 10+ и, для нативных тестов, компилятор C++17.

```bash
npm ci
npm run dev
```

Откройте `http://localhost:5173`.

Полная проверка:

```bash
npm run test:all
```

Производственная сборка:

```bash
npm run build
npm run preview
```

Каталог `dist/` является обычным статическим сайтом и может размещаться на
GitHub Pages или другом статическом хостинге.

## График «время–расстояние»

Нажмите **Time–distance** в верхней панели и выберите маршрут и временное
окно: 10, 20, 30 или 60 минут. По горизонтали показано время симуляции, по
вертикали — расстояние вдоль полной последовательности маршрута, включая
оба направления. Цветные линии показывают движение отдельных трамваев;
горизонтальные участки означают стоянку. На паузе график можно спокойно изучить.

Интервалы сравнивайте в одной и той же точке маршрута: сближение линий может
указывать на сбивание трамваев в группу. Накопление у конечной само по себе
не означает сбой — проверьте интервалы последующих отправлений.

Жёлтая подсветка означает **опоздание отправления более чем на 60 секунд**.
Плановое ожидание до назначенного времени не считается опозданием. После
отправления подсветка сохраняет его фактическое отклонение до назначения
нового слота; задержки на промежуточных остановках она пока не оценивает.

История собирается и при закрытом окне графика, хранится только в текущем
сеансе страницы и очищается при смене сценария, возврате времени назад или
перезагрузке. Доступно до 60 минут, но при большой группе трамваев лимит
в 60 000 записей может сократить этот период.

Подробнее: [Time–distance diagram](docs/OPERATIONS.md#timedistance-diagram)
(на английском).

## Где находится логика

```text
React + Canvas       интерфейс и визуализация
TypeScript           сценарии, пассажиры, ETA и эксперименты
C++ → WebAssembly    движение, торможение, энергия, безопасность,
                     остановки, двери, стрелки и депо
```

Максимально важная управляющая логика находится в C++ и вызывается через C ABI.
Это позволяет в будущем подключить физический Arduino-макет или MATLAB-модель,
не переписывая интерфейс симулятора.

## Важное ограничение

Проект является исследовательским симулятором, а не сертифицированной системой
управления реальным вагоном. Текущие проценты экономии получены в сравнительных
симуляционных экспериментах и не являются измеренной экономией реальных
операторов.

## Лицензия

До выбора публичной лицензии проект помечен как `UNLICENSED`. Публичный просмотр
кода сам по себе не разрешает его копирование и распространение.
