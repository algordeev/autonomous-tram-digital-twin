# Независимое ядро и физическая модель

## Граница модулей

`src/simulation-core/` не импортирует React, DOM или Canvas. В нём находятся:

- `fixed-step-clock.ts` — перевод нерегулярных кадров интерфейса в фиксированный расчётный шаг 50 мс;
- `vehicle-dynamics.ts` — продольная динамика вагона;
- `engine.ts` — сеть, маршруты, стрелки, светофоры, интервалы, депо и расписание;
- `headless.ts` — автономный прогон сценария и формирование JSON-отчёта;
- `index.ts` — публичный API ядра.

`src/App.tsx` отвечает только за интерфейс, ввод пользователя и Canvas. Canvas
получает `SimulationRenderState`, а не объект движка. Ядро передаёт физической
модели целевую скорость, применяет полученное перемещение и выдаёт неизменяемые
по соглашению снимки состояния.

## Headless-запуск

Полный движок можно запускать без браузера и сохранять результаты в JSON:

```bash
npm run simulate:headless -- --duration-hours 16 --sample-seconds 60 --output report.json
```

Параметры `--scenario`, `--tram-count` и `--start-minute` позволяют запускать
разные сети, размеры парка и моменты суточного расписания. Отчёт содержит
периодические срезы (с указанным шагом), интервалы, выпуск, предупреждения
и энергетический баланс по маршрутам.

## Продольная динамика

На каждом фиксированном шаге рассчитываются:

1. требуемое ускорение до целевой скорости;
2. ограничение рывка (jerk), ускорения и замедления;
3. сопротивление движению по формуле `A + Bv + Cv²`;
4. ограничение силы тяги и мощности двигателя;
5. служебное или экстренное торможение;
6. расход энергии и рекуперация.

### Профиль высоты маршрута №2

В сценариях Нижнего Новгорода восемь измеренных перепадов из презентации
«АТС АГ» записаны непосредственно в направленные сегменты пути. Их суммарный
спуск составляет 102 м. При текущей массе расчётного вагона 27,5 т формула даёт
`mgh = 7,64 кВт·ч`. В исходной презентации было указано 7,84 кВт·ч; это значение
сохранено как историческая ссылка, но не используется как точный результат
текущих параметров.

Модель различает четыре величины, которые нельзя смешивать:

- потенциальная энергия спуска `mgh`;
- механическая энергия торможения на колёсах;
- электрическая энергия после двигателя/инвертора (КПД 86%);
- энергия, фактически принятая сетью или НКЭ (коэффициент готовности 82%).

Частный участок маршрута №21 пока считается горизонтальным. На общей трассе с
маршрутом №2 он использует тот же профиль высоты. Окно `Energy → Open statistics`
показывает баланс отдельно по маршрутам и по всей сети.

Текущие параметры эталонного вагона находятся в
`REFERENCE_TRAM_PARAMETERS` в `vehicle-dynamics.ts`. Все величины заданы в SI:
килограммах, метрах, секундах, ньютонах и ваттах.

## Где использовать MATLAB/Simulink

MATLAB/Simulink лучше использовать не как основной runtime веб-симулятора, а
как эталонную модель и средство идентификации параметров. Рекомендуемый следующий
этап:

1. записать логи реального макета или вагона: время, скорость, ток/мощность,
   команду тяги и тормоза;
2. подобрать в MATLAB массу, коэффициенты `A/B/C`, пределы тяги и торможения;
3. прогнать одинаковый JSON-сценарий в MATLAB и TypeScript;
4. автоматически сравнить скорость, путь, тормозной путь и энергию с допусками.

Так браузер остаётся быстрым и автономным, а MATLAB служит проверяемым
инженерным эталоном, не становясь обязательной зависимостью проекта.
