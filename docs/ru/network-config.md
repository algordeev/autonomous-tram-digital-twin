# Конфигурации сетей и экспериментов

## Два уровня данных

Симулятор разделяет инфраструктуру и конкретный запуск:

- `src/config/networks/nizhny-route-2.json` — только кольцевой маршрут №2;
- `src/config/networks/nizhny-routes-2-21.json` — общая сеть маршрутов №2 и №21;
- experiment JSON — выбранная сеть и изменяемые условия одного опыта.

Network JSON содержит геометрию сегментов, последовательности маршрутов,
RFID/остановки, светофоры, стрелки, конфликтные зоны, депо, расписание,
высотный профиль и фон дорог. Перед запуском файл проходит проверку ссылочной
целостности: маршрут, RFID и светофор не могут ссылаться на отсутствующий путь.

## Выбор маршрутов

В правой панели `Network and routes` можно выбрать:

1. `Nizhny Novgorod · Tram 2`;
2. `Nizhny Novgorod · Routes 2 + 21`.

Смена сети перезапускает модель с её собственным парком, остановками,
стрелками, светофорами, депо и расписанием.

## Сохранение эксперимента

Панель `Experiment configuration` предлагает четыре операции:

- `Save on this computer` — сохранить до 20 конфигураций локально в браузере;
- `Load` — восстановить выбранную локальную конфигурацию;
- `Export JSON` — скачать переносимый файл;
- `Import JSON` — загрузить эксперимент с компьютера.

Эксперимент JSON v1 сохраняет:

- идентификатор сети;
- число вагонов по каждому маршруту и направлению;
- служебное время суток;
- ограничение скорости и скорость симуляции;
- автоматический выпуск, интервальное регулирование и политику приоритета;
- препятствия;
- положения стрелок;
- ручные режимы светофорных контроллеров;
- выбранный вагон и остановку.

После загрузки симуляция остаётся на паузе, чтобы состояние можно было
проверить перед запуском.

## Редактирование сети

JSON-файлы можно редактировать отдельно от C++-ядра. Координаты `points`
задаются в системе карты 1000×620, а реальные длины — в `lengthMeters`.
После изменения запустите:

```bash
npm run lint
npm run test:config
```

Команда `npm run generate:networks` перезаписывает JSON эталонной геометрией
из прежних TypeScript-построителей и нужна только при намеренной повторной
генерации исходных карт.
