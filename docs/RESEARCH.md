# Research Materials

## Project status brief

[Autonomous Tram Project Current Status](reports/Autonomous_Tram_Project_Current_Status.pdf)
is a six-page visual engineering brief covering implemented routes, architecture,
dispatch, passenger service, physical parameters, flywheel storage, benchmark
results, limitations and the MATLAB/hardware roadmap.

## Publication concepts

[Autonomous Tram Research Paper Ideas](reports/Autonomous_Tram_Research_Paper_Ideas.pdf)
presents three candidate publications:

1. passenger-energy trade-offs in headway regulation;
2. predictive energy-aware dispatch with wayside flywheel storage;
3. low-cost hardware-in-the-loop validation of a shared controller.

## Reproducibility position

The repository distinguishes implemented software evidence from future research
claims. Current benchmarks are deterministic simulator comparisons. A paper
should add repeated disturbances, uncertainty analysis, calibrated parameters
and a frozen release containing configuration, scripts and raw output.
